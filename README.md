# Hi, I'm Zejing Wang 👋

MSc student in Applied Mathematics at the University of Oslo, interested in scientific computing, machine learning and numerical methods for PDEs.

My current academic interests focus on numerical methods for hyperbolic conservation laws, with a particular interest in combining classical numerical methods with deep learning.

## Selected projects

### 🌊 [Hyperbolic PDE Solvers](https://github.com/zejingw1998/Pytorch-Hyperbolic-PDE)
Numerical experiments for hyperbolic conservation laws using Python and PyTorch, including finite-volume methods, Riemann problems, stability analysis and shock capturing.

### 🚀 [Computational Fluid Dynamics](https://github.com/zejingw1998/CFD-project)
A 1D Euler-equation solver with Sod shock-tube experiments, exact Riemann-solution comparison and advection tests.

### 🤖 [Artificial Intelligence and Machine Learning](https://github.com/zejingw1998/IN4050-Introduksjon-til-kunstig-intelligens-og-maskinl-ring)
Coursework and experiments in artificial intelligence and machine learning, including optimization, search methods, evolutionary algorithms and machine-learning techniques.

### 📊 [Applied Data Analysis and Machine Learning](https://github.com/zejingw1998/FYS-STK4155-Anvendt-dataanalyse-og-maskinl-ring)
Machine-learning experiments covering polynomial regression, bias–variance analysis, ridge and lasso regression, cross-validation and gradient-based optimization.

### 💬 [Natural Language Processing](https://github.com/zejingw1998/IN4080-Natural-Language-Processing-NLP-)
Implementations and experiments in natural language processing, including tokenization, BPE, N-gram language models, Laplace smoothing, text classification and neural-network methods.
